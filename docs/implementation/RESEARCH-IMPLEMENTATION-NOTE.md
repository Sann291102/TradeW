# Research workspace — implementation note (recon findings)

Written before any code was changed, per the brief's step 1.

## What the old `/research` was

A single 339-line client component (`apps/web/src/app/(workspace)/research/page.tsx`) with
no backend of any kind. `docs/audits/SIDEBAR-FEATURE-REALITY-AUDIT.md` §4.8 records the
detail; the load-bearing facts for this rebuild are:

- Every fundamental (`P/E 24.62`, `ROE 14.28%`, `EPS ₹119.61`, market cap, shareholding
  percentages) was a JSX literal, identical for every symbol.
- The "🤖 TradeW AI Summary" (`Bullish`, `Confidence 87%`, `Business Quality 9.2/10`) was
  generated by nothing. No service, no model, no data.
- Two different market-cap figures appeared on the same screen — ₹19,73,284 Cr in the
  header and ₹19,81,568 Cr in Key Metrics — which is itself proof both were invented.
- The price fell back to `symbol === 'RELIANCE' ? 2945.20 : 1500.00`, unmarked.
- Nine sub-tabs mutated only a highlight class. Four buttons had no `onClick`.

None of it is preserved.

## What genuinely does not exist and must be built

1. **No financial-data provider of any kind.** `packages/ai-core`'s `ResearchProvider` is a
   *web-search* interface (Tavily/Brave/Firecrawl) — it returns articles, not statements.
   `packages/market-data` covers quotes/candles/scrip-master only. Nothing in the repo
   models an income statement, balance sheet or cash-flow statement.
2. **No fundamentals persistence.** No Prisma model holds company metadata or statement
   facts. `Instrument` is a tradeable-contract row, not a company.
3. **No `/research` API surface.** No controller, service, DTO or module.
4. **No ratio maths.** Nothing anywhere computes P/E, ROE, ROIC or a coverage ratio.

## Chosen architecture

```
Twelve Data (vendor)
   ↓  TwelveDataFundamentalsProvider          packages/market-data/…/fundamentals/
FinancialDataProvider (interface)
   ↓  normalize → NormalizedFact { value, currency, period, periodType,
   ↓               source, sourceTimestamp, fetchedAt, basis: reported|derived }
ResearchCacheService (Prisma)                 services/api/src/research/
   ↓
ResearchService  → ratios.ts (pure) → reconciliation.ts (pure)
   ↓
ResearchController  (AuthGuard = free;  +CapabilityGuard('ai_research') on /analysis only)
   ↓
apps/web  lib/research/*  →  components/research/*
```

### Why Twelve Data
It is already the repository's configured vendor (`TWELVEDATA_API_KEY`, used by Forex and
US stocks), it covers NSE/BSE as well as US listings, and it publishes
`/profile`, `/statistics`, `/income_statement`, `/balance_sheet`, `/cash_flow` and
`/symbol_search` — the exact surface this page needs. Adding a second vendor would mean a
second key, a second quota and a second normalizer for no capability gain today. The
provider is behind an interface precisely so a second one can be added without touching
the service, the cache, the ratios or the UI.

### Why a Prisma cache is justified
Twelve Data's fundamentals endpoints are credit-metered and the free tier is 8 requests
per minute / 800 per day. Statements change quarterly. A process-local cache would be
lost on every deploy and multiplied by every replica. A durable, normalized fact table
makes upstream cost a function of *reporting periods*, not of traffic. Two models only:
`ResearchCompany` and `ResearchStatementFact`.

### The rule that shapes every type
Each section of the response is a discriminated union:

```ts
type ResearchSection<T> =
  | { available: true;  data: T; provenance: Provenance }
  | { available: false; reason: string; detail?: string };
```

When data is unavailable there is **no field to put a number in**. Fabrication is made
structurally impossible rather than merely discouraged. No `?? 0`, no `?? 24.3`, no
placeholder string anywhere in the render path.

### Free vs premium
- **Free (AuthGuard only):** search, overview, income statement, balance sheet, cash flow,
  ratios, historical series, ownership, segments. The brief requires P&L and balance sheet
  to be free; the rest of the statement set is free for the same reason — a trader cannot
  do fundamental research on half a company.
- **Premium (`@RequiresCapability('ai_research')`):** only the AI synthesis at
  `GET /research/:symbol/analysis`. That capability already exists and is already granted
  by three seeded plans, so no entitlement plumbing changes.

### AI grounding
The analysis endpoint builds its prompt **exclusively** from facts already fetched and
cached by the other endpoints, passes them as an explicit evidence block, and returns the
evidence list alongside the prose. No confidence score and no X/10 rating is produced,
because no scoring methodology exists in this repository — inventing one would repeat the
exact defect being removed. If the required statements are unavailable, the endpoint
returns `available: false` rather than asking a model to improvise.

## Verification plan

Outbound HTTPS is blocked in this environment, so the live vendor cannot be reached. Both
paths are still verified for real:

- **Unavailable path** — exercised against the real vendor client with no key and with an
  unreachable host, through the real controller, in a real browser.
- **Available path** — a local fixture server speaking the Twelve Data wire format, with
  `TWELVEDATA_API_URL` pointed at it. This is an existing, already-supported env override
  in `twelvedata.client.ts`; production code is unchanged and unaware. Every layer
  (HTTP → normalizer → cache → ratios → reconciliation → UI) runs for real.

Anything not exercised is reported as not exercised.
