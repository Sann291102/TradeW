# TradeW Knowledge Vault

Persistent engineering memory for AI coding agents working on this repo (Claude Code, and any other coding assistant used here). Not a database, not a log, not a place for prompts/responses or live market data — see [_INDEX.md](_INDEX.md) for the full scope split.

Open this folder as an Obsidian vault to browse it visually, or just read it as plain markdown — every note is self-contained with frontmatter and `[[wikilinks]]` for internal cross-references.

**Start at [_INDEX.md](_INDEX.md).** It's the catalog — read it before searching, and search before reasoning from scratch. The workflow and what belongs here vs. Sentinel's own Postgres-backed Persistent Knowledge Brain is documented in the project root `CLAUDE.md` (Rule 4) and in [Decisions/2026-07-17 - Obsidian Knowledge Layer adopted.md](Decisions/2026-07-17%20-%20Obsidian%20Knowledge%20Layer%20adopted.md).

## Folders

| Folder | Holds |

| `Patterns/` | Reusable engineering patterns, workflow improvements, dev standards |
| `Gotchas/` | Debugging discoveries, bug resolutions, lessons learned |

| `Agents/` | Agent responsibilities (Sentinel, TradeW AI, Claude Code subagents), prompt improvements |
| `Plans/` | Future implementation plans, milestones, strategy documentation |
| `API/` | API integration notes |
