# Trading Psychology

Cognitive and emotional patterns as observable trading behavior. This section strengthens Sentinel's behavioral analysis and educational guidance.

Use the **Psychology** template. Maps to the Brain's `trading-psychology` domain.

Existing Brain concepts: fomo, revenge-trading, loss-aversion, confirmation-bias, overtrading.

**Core patterns to document:**
- Fear and greed cycles
- FOMO (Fear of Missing Out)
- Revenge trading
- Confirmation bias
- Overconfidence
- Loss aversion
- Patience and discipline
- Emotional control
- Trade journaling as behavior modification
- Position sizing mindset
- Consistency and routine
- Professional trading habits

**Important:** Sentinel uses psychology knowledge to *identify and explain* emotional patterns, never to diagnose or prescribe. "Traders experiencing this pattern often..." is appropriate. "You should..." is not.
