# Books

Structured summaries and notes from trading books in `docs/Trading Books/`.

Use the **Book** template. One note per book.

**Rules:**
1. Never reproduce copyrighted text verbatim
2. Extract concepts, summarize ideas, build original educational notes
3. Short attributed quotes (under 15 words) for context are acceptable
4. Link extracted concepts to notes in other folders
5. Track ingestion progress in the book note's checklist
