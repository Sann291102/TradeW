# AI Summaries

AI-generated summaries and synthesis from book processing, concept extraction, and cross-domain analysis.

These notes are generated by the ingestion pipeline (Phase 2) and always require human review before promotion. Mark reviewed summaries with `status: reviewed`.

AI summaries feed the Brain's `MemoryRecord` store via `ConceptLearningEngine.ingest()` using the `LearnInput` interface with `kind: 'learning'` and `namespace: 'sentinel-learning'`.
