# Knowledge Graph

Domain overviews, relationship maps, and gap analysis for the Sentinel Concept Knowledge Graph.

This folder tracks:
- Which concepts exist vs. which are needed
- Relationship density between domains
- Coverage gaps that books or research should fill
- Domain health reports

The actual graph lives in Postgres (`ConceptNode`/`ConceptEdge` tables). Notes here are analysis and planning documents about the graph's state and growth, not the graph data itself.
