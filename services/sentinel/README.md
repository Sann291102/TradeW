# services/sentinel 🟢

The runtime for the **Sentinel (Safety Nets)** pillar — deliberately a separate service from `services/tradew-ai`, per the explicit decision that TradeW AI and Sentinel are not the same system (see `../../docs/product-architecture/README.md`). Runs on port 4010.

> **Companion runtime:** [`services/sentinel-py`](../sentinel-py/README.md) (Python/FastAPI, port 4011) is a newer, additive service under the Sentinel umbrella — the *personal strategy watcher* (parse a user's own text strategy → watch live candles → alert). It runs alongside this TypeScript service, which is unchanged; neither has been retired. See `SENTINEL_MASTER_PLAN.md`.

**Full blueprint:** `../../docs/product-architecture/SENTINEL.md` — the four-agent architecture (Market & Technical Intelligence, Emotion Intelligence, Trap & Safety Intelligence, Compliance & Audit) synthesized by a Sentinel Orchestrator, the composite Trap Detection signal design, full feature set, and UI workspace layout.

**Loads agent definitions from:** `../../agents/sentinel/`

**Reads (read-only, via `services/api`):** the user's own order/trade/position history from `services/trading-engine` — this is Sentinel's most sensitive data dependency and the main reason it can't just be a mode of `services/tradew-ai`.

**Exposes:** one internal endpoint, called only by `services/api`.

**Hard boundary:** never blocks or delays an order — it observes and comments in parallel with the normal order flow, it is not a gate in it. Every observation is logged with evidence and a SEBI-relevant label by the Compliance & Audit agent.

**Status:** 🟢 real, substantial code — not design-only. `src/` has grown well past 100 files, including a fully implemented Persistent Knowledge Brain (`src/brain/`, ~78% of planned scope per `SENTINEL_BRAIN_PROGRESS.md`), compliance, explainability, intelligence, orchestrator, reasoning (`reasoning.controller.ts`), the concept ontology/reasoning engine, the `sentinel-intelligence/` engine, and a `strategy/` lifecycle. The **publication gate** (`src/orchestrator/publication-gate.ts`) replaced the old fixed 85% threshold with a four-condition rule (adaptive confidence ≥ 70 + mandatory confirmations + no conflicts + corroboration). Broad unit-test coverage under `src/**/*.spec.ts`. Only Portfolio Intelligence remains unbuilt. Frontend note: this service is reached only through `services/api`, and that has never depended on how Sentinel is presented. Sentinel's frontend is the `/sentinel` workspace inside `apps/web`'s shared shell (`docs/product-architecture/SENTINEL.md` §5) — a 2026-07-21 direction change briefly proposed a standalone application instead and was reversed the same day, with no effect on this service either way.

**Execution evaluation (`src/execution/`).** Alongside the trader-facing `POST /observe`, this service exposes a service-token-only `POST /execution/evaluate` that `services/api`'s autonomous paper agents call. It reuses the *same* orchestrator read (`observeInternal` — one market read serves both paths) and adds four gates and a strike selection: **data quality** (`data-quality.ts` — candle history, bar freshness, index spot; the reason a silent fall-back to five-day-old stored candles can no longer trade), **agent strategy** (only the code-defined `agentTradable` roster; a YAML strategy file cannot grant itself order-placing rights), **index direction** (`index-direction.ts` — five weighted reads of the INDEX, which never consults the option chain, so premium movement can never imply market direction), and **evidence** (`evidence.ts` — each reader cites a `knowledge-base/*.yaml` concept id, and a strategy sees only the keys it declares). Strike selection lives here rather than on `/observe` deliberately: ranking one contract out of three *is* the thing `contract-alignment.ts` forbids near a trader.

**Hard boundary, restated for this path:** these gates decide whether an agent may open a PAPER position in its own account. Nothing on this path reaches a human, and this service still holds no Prisma binding to `Order`/`Trade`/`Position`. See [`docs/product-architecture/AUTONOMOUS-PAPER-AGENTS.md`](../../docs/product-architecture/AUTONOMOUS-PAPER-AGENTS.md).
